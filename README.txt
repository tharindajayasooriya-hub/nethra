Open index1.html in Chrome. Keep assets/ alongside it. To personalize, edit CONFIG near the bottom of index.html: name, signature, chatPhoto, smilePhoto, memories. Example smilePhoto:'assets/her-smile.jpg'. Put your actual pictures in assets. The chat and smile currently use clearly marked placeholders; the final heart uses your uploaded stickers. Fonts use Google Fonts online with local fallbacks. Upload this folder to a static host to share. No backend needed.
